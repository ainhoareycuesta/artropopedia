# ArtropoPedia

Guía ilustrada de artrópodos para aficionados y entomólogos de España: insectos, arácnidos y miriópodos.

**[Ver la web →](https://artropopedia.netlify.app/)**

## Qué incluye

- **Inicio:** últimas capturas y acceso rápido a las secciones.
- **Enciclopedia:** fichas de especies.
- **Capturas:** galería de avistamientos de la comunidad.
- **Foro:** espacio de conversación entre aficionados.
- **Registro:** formulario de alta de usuarios.

> Es un prototipo estático: el foro, las capturas y el registro son maquetas sin backend.

## Tecnologías

HTML5 · CSS3 · tipografías propias · desplegado en Netlify

## Ejecutar en local

```bash
git clone https://github.com/ainhoareycuesta/artropopedia.git
cd artropopedia
# abre index.html en el navegador
```

```
├── index.html, enciclopedia.html, capturas.html, foro.html, registro.html

├── fonts/      # tipografías
├── images/     # imágenes y capturas
```
